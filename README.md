# Vaultly — Fintech Landing Page

Vaultly is a modern fintech product concept designed to help people manage their money, track spending, set savings goals, and build better financial habits.

This project is a landing page built as part of The Odin Project's landing page assignment. It uses the original reference layout while adapting the content and branding to a personal finance product.

## Features

- Clean and simple navigation.
- Hero section introducing the Vaultly brand.
- Feature section highlighting money management tools.
- Testimonial-style section featuring the Vaultly philosophy.
- Call-to-action section encouraging users to get started.
- Footer with brand information.

## Built With

- HTML5
- CSS3
- Flexbox

## Project Goal

The goal of this project is to practise HTML and CSS fundamentals, especially page structure, layout, alignment, spacing, and styling, while creating a fintech-themed landing page.
